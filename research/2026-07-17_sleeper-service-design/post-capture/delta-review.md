# Delta review: the sleeper-service report vs the reforms drafted since it closed

Reviewer: session lead, 2026-07-17/18. The run's own research (integrity audits,
metrics archaeology, constitutional-reform plan, gap-classes/repair-quality
program, record layer, law-not-memory doctrine, E-queue) postdates the debate's
evidence pins. This review enumerates where those changes alter the plan the
report specifies — and where they don't.

## Headline: decisions survive, substrate shifts

None of the reforms overturn a design DECISION: artifact-mining over introspection,
one pick, deterministic ranking, smoke-scale research, write-fence to
research/+ideas/, seven gate layers, never-scheduled graduation — all stand.
What changes is the SUBSTRATE the loop reads and the instruments it carries.
Estimate: §1 (consumption) takes the largest rewrite; §2 minor; §3 nearly
untouched; §4 converges with work already planned; §5 gains instruments.
~25-35% of design text, ~0% of design verdicts.

## D1. The input inventory grows — and gets structured (§1.3)

The report's harvest reads friction.md, board-telemetry.jsonl, run records,
backlog/doubts, red's gap-pattern memory. The reforms add first-class surfaces
the report could not have known:
- `law/` — precedent with human review outcomes (affirmed/reversed): the single
  richest "what does the human actually want" signal the suite will possess.
- `feov-memory/` craft files — blue's regression classes + capture-computed
  calibration stats (structured STATS sections, script-written).
- `records/` JSONL (seats/board/friction) — replaces several markdown regex
  parses harvest.mjs would otherwise need; the R5-10 est_complexity problem
  class (unparseable prose fields) shrinks by construction.
- New telemetry: repair_regression_rate, class_mass, ruling mix, petition
  counts, context-fill%.
Build note: harvest.mjs's input table should be written against the record layer
from day one rather than retrofitted.

## D2. Ranking gains real features (§1.4)

The report's ranking divisor est_complexity is inert at the pin (R5-10, red's own
finding). Gap-classes recurrence counts, repair-regression contributions, and
bench reversal rates are exactly the "class of problem" pressure signals a
ranking wants — deterministic, already computed at capture, zero tokens. The
ranking arithmetic section should consume them.

## D3. One provenance convention, not two (§1.5 + R5-3 vs record layer + law)

The report's positively-defined corroboration pool (wrapper-stamped origin
markers, fail-closed quarantine) and the reform's memory-poisoning guards
(agent-written state persuasive-until-human-affirmed; git-tracked deltas) are
the SAME mechanism evolved twice. The build should implement one origin/
provenance convention serving both: seats.jsonl self-registration rows are the
natural carrier. This also settles R5-4's "slug unknowable after hard-kill" —
the wrapper logs sub-run dir PATHS at creation into a record, which is the
record layer's exact shape.

## D4. The UNVERIFIED-tail class dissolves under #26 (verdict inheritance)

The run's largest inheritance — "round-5 repairs are blue-claimed, not
red-verified; build PR must re-audit the CHANGELOG Round 5 edit set" — is an
artifact of the OLD round ordering (judge before blue; ceiling fires after
blue's last revision). Under closing-arguments (#26, merged ordering:
audit → response → judgment with closings), every round ends with the judge
ruling on blue's ACTUAL final state; a ceiling stop leaves no unaudited
revision behind. Future runs do not produce this inheritance class. (The
current report's re-audit obligation still stands — this delta is forward-only.)

## D5. R1-7's enum misfit is already answered (petitions + dispositions)

The judge's friction ("no routed_to_infrastructure disposition; risk_accepted
is least-wrong") and the R1-7 pin defect map directly onto the reform's
petition mechanism (class: constitutional/infrastructure, short-circuit to the
bench) and the review docket. The build PR should also fix the actual debt:
setup validates every pin (`git cat-file -e <pin>:<path>`) and fails loudly.

## D6. Memory delivery rule applies to the loop itself (§1.4/§2.3)

Backfill evidence: memory-as-reading is worthless (run-5 lanes verifiably read
the gap-pattern file and committed both warned patterns; red's duty-embedded
patterns caught both). Sleeper's nightly research consumes red's memory — it
must COMPILE entries into the pick's working checklist (manifest lines), not
mount the file for reading. Same rule for the stub template: a stub citing a
gap-pattern should carry the pattern as a question to answer, not a fact.

## D7. Tiering gains a measured floor (§5.2 + scheduling doc)

"Cheapen redundancy, never judgment" now has a hard number: judgment seats need
a 1M-window model — the merge seat peaks at 270k, breaching a 200k window
(haiku). The scheduling doc's model-tier table should state the constraint;
sleeper's smoke-scale merges are smaller but the floor belongs in the doc.

## D8. The Catechism class gets a structural fix (assembly auditability)

The assembly's own disclosure ("the catechism as a unit was never itself a red
target") names a surface class: judge-assembled synthesis wearing the debate's
authority unaudited. Reform answer: bench-authored sections are OPINIONS —
flagged for_human_review on the judicial record — and/or the terminal red pass
spot-audits assembly-owned sections. Red's out-of-band audit of this run's
catechism (in flight) is the empirical test of how much that class costs.

## Disposition (operator decision, 2026-07-18)

The report's job is DONE as research and its role now is LEARNING ARTIFACT and
FUTURE-RUN INPUT — not an implementation plan. No build proceeds from it
directly. Sequence: land the constitutional/structural reforms first; a future
FEOV run (post-reform, absorbing D1-D8 and the reformed engine's own record
surfaces) produces the buildable design; this report and this delta review are
pinned inputs to that run. E5 (surprise ledger) re-anchors to that future
build. The re-audit obligation on the round-5 edit set transfers to the future
run's evidence intake (it re-pins this report and audits what it uses). What
the report contributes NOW: the composition-failure taxonomy (invariants 7/8,
structural closes), the gate-stack architecture as debated precedent, the
friction harvest (already absorbed into the reforms), and the Catechism audit
(D8's empirical test, in flight).
