# sleeper-service

> *The GSV quietly running vast hidden projects.*

The autonomous-learning plugin of [Special Circumstances](../../README.md). It improves the system while you sleep — always human-gated at the promotion step.

**Will carry:** `/self-improve` (daily default cadence), `/graduate`, a continuous-learning promotion ladder (insight → MEMORY → rule-skill → cheatsheet), and scheduling recipes. Writes only to `research/` and `ideas/`; promotion into rules/skills requires the human. Requires frank-exchange-of-views.
