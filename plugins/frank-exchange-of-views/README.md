# frank-exchange-of-views

> *A heated argument, diplomatically put.*

The research debate engine of [Special Circumstances](../../README.md). Given a topic, it produces a verified research deliverable with the full adversarial record preserved.

**Will carry:** an *additive-only* blue team (union, never summary), a *subtractive* red team that owns the PASS/FAIL gate, a lead (workflow script + lead-judge) that runs the mechanics and the final compromise, best-of-N lanes/lenses, a Heilmeier Catechism, and per-run artifacts (living blue/red reports, preserved candidates, a full debate transcript). Termination is judged (red-PASS or deadlock/spinning), not counted.

Status: scaffold only (Phase 0). Design: [`plans/claude-port-plan.md`](../../plans/claude-port-plan.md) §3b.
