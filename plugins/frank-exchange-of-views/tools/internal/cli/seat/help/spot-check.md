## detail

A duty every round owes, including the rounds with nothing to sample.

The floor is COMPUTED from the board at verify time — the archive's size at round start is replayed state no seat can author — so a round claiming an empty archive the board contradicts fails.

The explicit empty form is for the rounds where the archive really was empty. Silence is not that statement.
