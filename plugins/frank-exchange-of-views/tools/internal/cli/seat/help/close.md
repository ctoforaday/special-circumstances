## menu

close a gap with the verification you did THIS sitting, naming what you checked it against

## detail

THE VERIFICATION TRIPLE IS THE POINT: this verb asserts the repair was checked THIS SITTING, by you — who verified it, with what, and against which exact file or ref.

For a closure the record already holds — work an earlier sitting did, which you are restating rather than re-attesting — use `carry`, which needs no triple because it makes no fresh claim. Re-closing carried work here double-counts the closure history.
