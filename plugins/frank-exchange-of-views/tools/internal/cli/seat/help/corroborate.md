## menu

go and find a source blue never cited, when the claim has no anchor but the source is obtainable

## detail

corroborate a claim from a source YOU found — one blue never cited, so there is no anchor: --url <u> --title <t> --quote "..." --as supports|refutes|absent|… --confidence high|medium|low --reason "<what the source actually says>". THIS IS THE VERB FOR A CLAIM WITH NO CITATION when the source is obtainable — it answers whether the claim is true in the WORLD, where a finding answers whether the TEXT stands up, and it is what makes "nobody cited this" checkable instead of merely raised. To adjudicate a citation blue DID author, use `verify` instead: it names the citation by its anchor.
