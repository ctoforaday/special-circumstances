## menu

take a claim out of the report, when it cannot stand and no edit will save it

## detail

A claim leaves the report only through this verb — never by quietly not being there any more. `edit` refuses a replacement that drops an anchor, so the anchors a claim rested on leave here, named on the record.

An anchored claim leaves in two steps: `edit` the claim out — the edit carries its anchors, because an edit may carry an anchor but never drop one — then retire it here, quoting the WHOLE of what the edit cut, or whole sentences of it. The anchors that stood on those sentences in that edit are the claim's. Each that stands bare now — no prose before it in its sentence — leaves with it, whatever its kind: no orphan footnote, no empty bullet, and an edit that cut several claims lets each leave with its own reason. One the edit left on prose that still stands — the rest of its sentence, or text the edit wrote — stays unless you name it: name it when it backed only this claim, and the tool checks it against the edit that took the claim out. A fragment of a sentence takes nothing out, and while that sentence's anchors stand bare it is refused, naming them and the sentence to quote. The result says which anchors left and which stayed.

Name what replaces it where something does.
