# prosthetic-conscience

> *The drone that keeps you honest.*

The base plugin of [Special Circumstances](../../README.md). It carries the shared rule substrate the other plugins preload, plus the adversarial-partner behaviour for interactive work.

**Will carry:** Design-by-Contract rules as discrete skills (critical-stance, anti-spinning, semantic-consent, …), pair programming, spec-driven development + `/plan-audit`, project memory, proficiency skills (git/markdown/qlty), quality hooks, a standalone `validation-loop`, and environment preflight (`requirements.json` + `/prosthetic-conscience:doctor`).

Status: scaffold only (Phase 0). Design: [`plans/claude-port-plan.md`](../../plans/claude-port-plan.md) §3a.
