# qlty-proficiency

- BEFORE running quality operations, YOU MUST confirm qlty is present (the shared toolchain probe / `/prosthetic-conscience:doctor`); when absent, say so and skip — do not improvise per-language substitutes without being asked.
- During formatting and linting, YOU MUST use the patterns in this skill's `references/CHEATSHEET.md` (`qlty fmt`, `qlty check`, sample/config commands) rather than ad-hoc tool invocations.
