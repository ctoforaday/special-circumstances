# proposed gap class — `misplaced-citation-anchor` [PROPOSED — not in the registry until adopted]

Coined by `red-merge-r3` during `2026-09-02_quadratic-formula`. It is NOT staged into any later run:
an unreviewed class validating a future `--class` is the registry losing the only thing it
means. Adopting it means adding the slug to `feov-memory/class-registry.json` by hand.

- **definition**: A citation anchor is spliced at a span other than the claim it was recorded against, so the assembled footnote backs text it is not about while the claim it was fetched for ships unreferenced.
- **neighbour**: `unsourced-quotation-or-appeal`
- **distinguisher**: Does a source exist and stand recorded against this claim? If yes and only its placement is wrong, this class; if no source exists at all, unsourced-quotation-or-appeal.
- **first used on**: R3-4

The three fields above are the seat's own words, refused at the write if any were missing
(`record.validateClassNew`), so this proposal is well-formed by construction. What a
reviewer decides is whether it DISCRIMINATES — whether the distinguisher actually separates
it from its neighbour on a case where both are arguable.
